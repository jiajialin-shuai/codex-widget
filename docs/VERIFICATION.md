# 验收记录

日期：2026-10-14。测试环境：Apple Silicon，macOS 27.0，Xcode 27.0。源码没有使用第三方运行库。

## 已验证

- `scripts/check.sh --live`：窗口顺序互换、按 300/10080 分钟分类、缺字段保留未知、非法百分比、其他额度池排除、map fallback、过期缓存、JSON 往返通过。
- 静默 CLI 超时后进程被回收；查询中退出也取消并回收自己的子进程。检查明确使用 `kill(pid, 0)` 与 `ESRCH`。
- 本机真实 `account/rateLimits/read` 返回周额度、五小时额度、重置卡数量和到期时间；两次查询耗时约 1.8–2.1 秒。原始响应不写入仓库。
- Release 构建、arm64/x86_64 Universal Binary、应用/扩展 ad-hoc 深度签名验证通过。应用包约 2 MB。
- AppKit/SwiftUI 实际窗口检查：三种尺寸的真实数据预览可读，无明显裁切。离线渲染的小/中/大号、浅/深色六张示例图另外检查了布局；示例图不能代替桌面材质验收。
- WidgetKit 扩展通过 `pluginkit` 注册，仅保留安装位置的一份插件记录。
- `scripts/check-widget.sh`：相同 Widget 加载代码在有 App Sandbox + network.client + 同样 ATS 设置的测试应用中读取真实快照，并写入自己的缓存。
- 主程序退出时，沙盒 Widget 加载代码能读取既有缓存并标记离线。
- 只读快照服务仅监听 `127.0.0.1:49763`。分段 HTTP 请求正常读取；POST 和其他路径返回 404；快照无 Token、邮箱、账号 ID、卡 ID。
- 菜单栏开关实际操作：可以显示/隐藏，最终保持隐藏；隐藏图标后后台查询仍正常；重新打开应用可进入设置。
- 原生透明桌面面板在实际桌面上创建，截图检查双圆环、数字、标签；双击进入设置通过，开关启用通过。用户反馈第一版半透明效果“还可以”，随后要求加强玻璃感；已改用 `NSGlassEffectView`，支持通透/柔和，无互动动画。

## 资源抽样与范围

第一版主程序开启/检查预览后的物理内存（`footprint`）约 36 MB、峰值约 37 MB；3 次 `top` 抽样 CPU 为 0.0–0.2%。RSS 单次读数约 12–14 MiB，不等于物理内存，因此不以 RSS 宣称真实占用。该数字不直接复用于最后的玻璃版本。

最终版本，仅启用小号原生玻璃桌面组件、关闭设置预览、隐藏菜单栏图标：`footprint` 物理内存约 20 MB、峰值约 21 MB；3 次 `top` 抽样 CPU 均为 0.0%。该样本只统计主进程，不包括独立 WidgetKit 扩展或 WindowServer 的合成成本。

背景刷新不启动长期 CLI，不扫描磁盘/日志，不每秒轮询，也不捕获桌面或壁纸图像。系统材质的合成由 macOS 处理；系统壁纸和窗口变化仍可能影响合成成本。

## 限制与待验收

- 桌面 WidgetKit 卡片：用户确认已经添加，并两次反馈背景像不透明色块。`Color.clear` 和 `ultraThinMaterial` 均不能在本机验收为想要的效果。因此另提供原生透明面板，不把设置预览的玻璃效果当成 WidgetKit 效果。
- CUA 在 Notification Center 的多桌面窗口上无法稳定选择 Codex 卡片；原生桌面面板属于本应用，可以直接选择和检查。不同壁纸、明暗/增对比/减少透明度的最终玻璃视觉仍需分别验收。
- macOS 14/15 材质回退、Intel 实机、不同屏幕、多显示器位置恢复、休眠/唤醒、长时间 WidgetKit 调度和开机自启尚未完整实测。
- 尚无 Developer ID 签名、公证或公开安装包；仓库按用户要求保持私有，后续再开源。
